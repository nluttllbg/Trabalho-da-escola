## 🌾 Sobre o Projeto

Plataforma web de alta performance desenvolvida para a **AGIJ FERT**, apresentando o catálogo técnico de fertilizantes especiais, condicionadores de solo, bioestimulantes e soluções nutricionais para as lavouras do Cerrado (Soja, Milho Safrinha, Algodão e Pastagens).

### Principais Funcionalidades:
1. **Simulador de Nutrição do Cerrado**: Recomendação agronômica por cultura, estádio fenológico, tipo de solo e área (hectares) com cálculo de sacas extras e exportação direta para o WhatsApp.
2. **Catálogo Técnico com Filtros**: 6 linhas completas com garantias mínimas registradas, dosagens e fichas técnicas detalhadas.
3. **Manejo Fisiológico por Cultura**: Análise de gargalos agronômicos em Mato Grosso e janelas de aplicação (TS, V2-V4, R1, R3-R5).
4. **Calculadora de ROI (Retorno Econômico)**: Gráficos comparativos de ganho financeiro e sacas/ha.
5. **Casos Reais no Campo**: Resultados comprovados em Sorriso, Lucas do Rio Verde e Nova Mutum.
6. **Gerador Dinâmico de Cotação para WhatsApp**: Formulário com montagem de mensagem personalizada e envio direto para **(66) 99651-2455**.
7. **Transparência Total de Fotografias**: Modal e tabela com o registro de todas as 13 fotografias reais, autores, links e licenças comerciais livres (Zero IA em fotos).

---

## 🛠️ Tecnologias Utilizadas

- **React 19** + **TypeScript**
- **Vite 7** + **Tailwind CSS v4**
- **Framer Motion**: Animações fluidas baseadas nos princípios de design engineering de Emil Kowalski (`cubic-bezier(0.23, 1, 0.32, 1)`, aceleração de hardware e suporte estrito a `prefers-reduced-motion`).
- **Lucide Icons**: Ícones vetorizados consistentes.

O projeto já contém:

### Como publicar no repositório GitHub desejado:
```bash
git init
git add .
git commit -m "feat: site oficial AGIJ FERT completo"
git branch -M main
git remote add origin https://github.com/SEU_USUARIO/SEU_REPOSITORIO.git

```
*No GitHub: acesse Settings > Pages > Source e selecione "GitHub Actions".*
